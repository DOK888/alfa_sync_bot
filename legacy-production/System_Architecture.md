# Архитектура и Устройство Системы: AlfaCRM Sync & Hermes Integration

Этот документ описывает всю текущую архитектуру проекта, логику работы скриптов и планы по дальнейшему масштабированию. Создано для того, чтобы не потерять контекст и позволить ИИ-ассистенту (Hermes) понимать, как всё устроено под капотом.

## 1. Общая суть и Инфраструктура
**Цель:** Автоматизировать рутинный перенос расписания из двух аккаунтов AlfaCRM (Тетрика и WellKid) в личные календари (Google Calendar) и организовать автономный сбор финансовых данных и списков учеников для дальнейшей аналитики в Obsidian и генерации отчетов с помощью ИИ.

**Инфраструктура:**
- **Сервер:** Домашний сервер `hermes` (IP: `192.168.31.8`).
- **Среда выполнения:** Изолированный Docker-контейнер `alfa_sync_bot` (ОС: Ubuntu/Debian), работающий в фоновом режиме 24/7.
- **Связь с сервером:** Осуществляется по SSH (`hermes@192.168.31.8`). 
- **Docker Volumes (Проброс папок):** 
  - Папка с авторизацией (сессиями): `~/alfa_sync/auth` -> `/workspace/auth`
  - Папка Obsidian (для выгрузки данных): `/volume1/obsidian/AlfaCRM/data` -> `/vault/AlfaCRM/data`

## 2. Как устроена работа под капотом (Скрипты)

### `sync_daemon.py` (Главный парсер и диспетчер)
- **Запуск:** Использует библиотеку `schedule`. Просыпается ровно **раз в час**.
- **Логика Парсинга:** Мы отказались от ненадежного кликанья по HTML-таблицам. Вместо этого бот делает прямой запрос к скрытому внутреннему API календаря: `/teacher/1/calendar/fetch?start=YYYY-MM-DD...`
- **Обработка данных:** 
  - Сервер отдает чистый JSON. 
  - Скрипт очищает названия групп от HTML-мусора.
  - **Время:** Скрипт прибавляет **+2 часа** (Конвертация Москвы в Екатеринбург).
  - **Ученики (Customers):** Скрипт глубоко парсит скрытое поле `customers`, извлекая и очищая реальные имена всех учеников для каждой группы.
- **Финансы:** 
  - Тетрика: 60 мин = 800 руб, 90 мин = 1200 руб.
  - WellKid: Групповые уроки ("ПМП", "ППН" и те, где есть цифры) пропускаются (0 руб). Индивидуальные: 60 мин = 400 руб, 30 мин = 200 руб.
- **Экспорт:** Формируется итоговый `alfa_data_parsed.json`, который ложится напрямую в хранилище Obsidian.

### `tg_bot.py` (Интерфейс, ИИ и Уведомления)
- **Функции:** Утренняя сводка расписания (09:00), напоминания за 1 час до урока, вечерняя сводка по ЗП и итогам дня (23:00).
- **ИИ-Генерация Отчетов:** Интеграция с Google Gemini (API AI Studio). Бот позволяет выбрать сегодняшний урок, парсит из JSON имена всех учеников и тему, а затем:
  - Генерирует уникальный текст-отчет для **каждого ученика**.
  - Умеет принимать короткие голосовые сообщения от преподавателя с комментариями по уроку (или текст), анализирует их и вписывает в шаблон.
  - Поддерживает быстрое отключение ИИ для экономии ресурсов.

### `google_sync.py` (Интеграция с Google Calendar)
- Подключение: Использует Google Service Account. 
- Идемпотентность (Защита от дублей): Хэширование уроков (UID в описании).

## 3. Выполненные Этапы (Готово)

✅ **Этап 1: Дашборд в Obsidian (Визуализация)**
- Использование плагинов `Dataview` / `Obsidian Charts` для чтения `alfa_data_parsed.json`. Автоматический расчет недельного расписания и финансов.

✅ **Этап 2: Telegram-бот (Push-Уведомления и Управление)**
- Полностью автономный бот в одном контейнере с парсером.

✅ **Этап 3: ИИ-Аналитика и Генерация Отчетов**
- Нейросеть (Gemini 1.5/3.1 Flash) внедрена прямо в Telegram-бота. Больше не нужно копировать транскрипции из "Толка". Достаточно надиктовать 10-секундное голосовое в бота после урока, и он сгенерирует готовый персональный отзыв для каждого ученика из группы.

## 4. План Дальнейшего Масштабирования и Интеграция с Hermes

### Идеи для будущих улучшений:
1. **Глобальный AI-Ассистент (Hermes):** 
   - Вынести всю логику Gemini из локального бота в полноценного ассистента Hermes. Hermes сможет читать `alfa_data_parsed.json` напрямую из своей памяти и самостоятельно отвечать на сложные аналитические запросы (например: *"Кто из учеников в группе Блоксели_20 чаще всего ошибается по моим отчетам?"*).
2. **База Знаний (RAG):**
   - Сохранять все сгенерированные отчеты в отдельные `.md` файлы в Obsidian, чтобы формировать долгосрочную историю успеваемости каждого ученика.
3. **Авто-транскрибация Толка:**
   - Если Толк получит публичное API, настроить Webhook: как только видео обработано, скрипт автоматически скачивает транскрипцию, Hermes её анализирует и присылает детальный саммари без какого-либо участия преподавателя. 
4. **Сценарии Автоматизации (Умный дом / Рабочий процесс):**
   - Бот может триггерить локальные скрипты на ПК (через тот же сервер): включать нужные программы (Zoom, Толк) ровно за 5 минут до урока, менять свет в комнате или переводить телефон в режим "Не беспокоить".
